# Capstone-Project
My capstone project for university was a group project called Perspectives.ai, which is a conceptual AI-powered browser extension designed to improve media literacy and help users critically evaluate online news sources. The project was made for a design challenge for the technology company IBM Canada.

## Overview
This tool is intended to provide readers with contextual information about news articles, including source credibility, author background, bias indicators, and alternative perspectives, enabling users to make more informed decisions about the information they consume.

The project explored how artificial intelligence, interface design, and data visualization can support digital literacy by making complex information about media bias and reliability more accessible to everyday readers.

The final outcome included product research, UX/UI design prototypes, feature planning, and a strategic framework for implementing the tool as a browser-based platform.

## Objectives
<ul>
  <li>Improve media literacy and critical thinking when consuming online news</li>
  <li>Provide transparent context about news sources and authors</li>
  <li>Present multiple perspectives on the same topic to reduce echo chambers</li>
  <li>Integrate seamlessly into users' normal browsing behaviour</li>
</ul>
